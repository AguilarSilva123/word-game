# WORD GAME

Jogo de caça-palavras em inglês construído como Progressive Web App (PWA) com HTML, CSS e JavaScript puros — sem frameworks.

- 📱 Responsivo: layout adaptado para celular e para desktop
- ⚡ Instalável como app no celular e no PC
- 🌐 Funciona offline, graças ao service worker
- 🧠 Sistema de dicas, timer e pontuação com multiplicador
